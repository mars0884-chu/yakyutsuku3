# やきゅつく3 查人・攻略・金手指

獨立的《プロ野球チームをつくろう！3》查詢 PWA。與其他棒球 GM 專案無關。

## 主功能

- 選手搜尋：GitHub Pages 建置時從 Gamezukushi 15 個名冊頁產生完整 3,767 人資料。
- 批次找人：桌機與手機共用同一套固定 OFFICE MENU 版面 CV 主流程，先做本機字形／版面比對，再與 3,767 人資料庫交叉約束；iPhone/iPad 不啟動 PaddleOCR，桌機的 PaddleOCR／Tesseract 只做可選複核。低信心只顯示候選。
- 攻略：既有 742 筆整理資料與 31 章整合攻略全文搜尋；R35 增補可讀的 Wazap 30筆外國球員對照中未收錄的 22 筆、7筆經營企劃、1項季節活動，日文原名與繁中並列；改造碼與正常攻略分頁且全面去重。
- 金手指：XT／PAR／PCSX2 依來源分類；R36 整理巴哈 2018 舊碼，原文不完整者不得直接使用。
- R37 考古：登錄四個歷史日文攻略站名（原址待查）與 2007 設施玩家策略；網站與來源同步更新。
- PWA：HTTPS 下可安裝、Service Worker 快取，避免 iPhone Edge 以 `file://` 開啟造成 worker/WASM/CORS 問題。

## 資料管理

`data/players.json` 不手工維護。Pages workflow 每次部署重新讀取 15 個來源頁，任何一頁筆數與預期不同就停止部署，避免不完整資料覆蓋正式版。

主畫面使用《プロ野球チームをつくろう！3》封面縮圖作識別；若來源圖暫時無法載入，回退到本專案的本地圖示。

## R63：辨識信心分級調整（2026-10-14）

- 人工評估之前134名次選／候選多數首選正確，先把**推定**條件分成舊嚴格門檻、截圖分類強佐證、首選高視覺分數三條可解釋路徑。第一候選至少有合理分差、視覺分數，而且同名多筆不能推定；截圖讀到分類卻與候選守位不符不能推定。
